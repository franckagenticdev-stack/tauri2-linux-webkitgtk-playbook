# Contributing / Contribuer

Thank you for helping improve this troubleshooting reference. Contributions in English or French are welcome.

1. First search existing Issues and Discussions (if enabled).
2. Provide distro/version, Tauri CLI, WebKitGTK, Rust toolchain, display server and **reproducible steps**.
3. Distinguish **observed PASS/FAIL** from plausible hypotheses; never claim a universal fix from one environment.
4. Submit concise Pull Requests with before/after documentation and a safety review.
5. Never include private repository names, user paths, usernames, passwords, tokens, access keys or proprietary code.
6. Do not propose destructive cache cleanup or privileged commands as default troubleshooting steps.

## Français

Les contributions en français et en anglais sont les bienvenues. Précisez versions, étapes de reproduction et résultats réels. Séparez les hypothèses des tests confirmés. Retirez toutes les informations privées ; ne proposez pas d'effacer globalement le cache ou d'exécuter `sudo` sans justification et consentement.
